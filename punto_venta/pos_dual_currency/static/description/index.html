POS Dual Currency Display

The Odoo POS Dual Currency module enhances the Point of Sale (POS) system by allowing transactions to be handled and displayed in two currencies simultaneously. This is particularly useful for businesses operating in multi-currency environments or catering to international customers. The module integrates seamlessly with Odoo's existing POS framework, providing both backend configurations and frontend user interface adjustments to support dual currency operations.



Features
  • Enable Dual Currency: A toggle option in POS settings to activate or deactivate dual currency functionality.
  • Second Currency Selection: Allows selection of a secondary currency from Odoo’s available currencies.
  • Dual Currency Display: Shows transaction amounts in both the company’s base currency and the selected second currency on the POS screen.
  • Receipt Printing: Prints receipts displaying amounts in both currencies for customer reference.
  • Order Summary: Displays dual currency totals, taxes, and change due in the POS order summary.
  • Support Community and Enterprise Editions
Scenario Workflow

1. Configure dual currency settings in the backend.

2. Select a secondary currency in the POS configuration.

3. Conduct transactions in the POS interface with dual currency display.

4. Print receipts displaying both currencies for customer clarity.

5. Have no affect on finanical entries.
